# קוזין אונליין — גרסת בטא מבודדת

שרת WebSocket לשני שחקנים אמיתיים עם קוד חדר בן 6 ספרות, מיקום ומכשולים משותפים ומצלמה נפרדת בכל לקוח. יש מסך מוכןות, ריצה, קפיצה כפולה וסיום מרדף.

המשחק הראשי ב־index.html **לא שונה**. לגרסת הבטא הזו אין כתיבה לחשבונות, לשמירות, למלאי, למטבעות או לדירוגים.

## פריסה ל־Render (בחינם)
באפשרות Blueprint: `render.yaml`.
באפשרות Web Service: Build command: `cd kozin-online && npm install --omit=dev`. Start command: `cd kozin-online && npm start`. Node runtime, Frankfurt, plan: free.
בדיקת שרת: `GET /health`.

## ממשק
דף `/online.html` ב־Vercel. שני המשתמשים יוצרים/מצטרפים לחדר, לוחצים "מוכן" ומשחקים באותו מסלול. הכניסה אינה דורשת חשבון.

## הגנות ומגבלות
דגם בטא: חדרים נשמרים בזיכרון השרת בלבד, ועלולים להיעלם כשהשרת החינמי הולך לישון או נפרס מחדש. אין סנכרון שמירה בין מכשירים, אין מערכת חברים ואין מכניקות החנות/כוחות המשחק המלא. אין לבצע קנייה או חיבור מכיל מידע אישי באמצעות קוד הדוגמה.
