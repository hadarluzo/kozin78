# Michael and Savta running animation

Assets: `michael-run.webp`, `tzippy-run.webp` and `{michael,tzippy}-{tech,fahima,dogs,paisley}-run.webp` in this directory.
Generated with the built-in image-generation tool from the existing character atlases, then encoded to WebP preserving alpha. Eight chronological phases, four columns by two rows. The run loader uses one constant scale per cycle and fixed head registration. It replaces running frames 0–7 for both base and ALL FOUR shop outfits, leaving portraits, actions and powers intact. Loaded before the existing game-ready signal in both solo and online. Outfit variants are installed after Bracha/Fahima's independent costume copies, so their approved identities are not changed.

Prompt set (identity-preserving game sprite edits):

- Michael: same young man, curly dark fringe, grey knitted kippah, olive hoodie, black cargo trousers and white sneakers. Transparent 4×2 full-body right-facing atlas; eight-phase alternating contact, passing, push-off and flight cycle, opposite arm swing, consistent proportions and face, clean alpha, no labels or scenery.
- Savta/Tzippy: same elderly smiling woman, grey-brown hair, burgundy caftan with gold embroidery and gold low shoes. Transparent 4×2 right-facing atlas; eight-phase light jog with alternating feet and counter-swinging arms, weighted modest moving hem, stable recognizable face and proportions, clean alpha, no labels or scenery.

Outfit-edit prompt, applied separately to each of the eight variants: use the corrected eight-frame cycle as edit target and original shop atlas as clothing reference; change only clothing to the exact referenced outfit, retain face, age, hair, body proportions, chronological poses, 4×2 registration and transparent background.
